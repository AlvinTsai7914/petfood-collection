  FeedRadar API 文件

  Base URL（Railway）：https://<your-railway-domain>

  所有回應皆為 JSON，格式：
  { "success": true, "data": { ... } }
  { "success": false, "error": { "code": "SERVER_ERROR", "message": "..." } }

  ---
  GET /api/filters

  取得所有可用的篩選選項。

  回應

  {
    "success": true,
    "data": {
      "brands": [
        { "value": "皇家", "label": "皇家", "count": 42 }
      ],
      "ingredients": [
        { "value": "雞肉", "label": "雞肉", "count": 85 }
      ],
      "petTypes": [
        { "value": "cat", "label": "貓", "count": 120 },
        { "value": "dog", "label": "狗", "count": 98 }
      ],
      "forms": [
        { "value": "wet",  "label": "濕食", "count": 60 },
        { "value": "dry",  "label": "乾糧", "count": 80 }
      ],
      "isPrescription": [
        { "value": "true", "label": "處方飼料", "count": 15 }
      ]
    }
  }

  ┌───────┬───────────────────────────────────┐
  │ 欄位  │               說明                │
  ├───────┼───────────────────────────────────┤
  │ value │ 傳給 /api/products 查詢時使用的值 │
  ├───────┼───────────────────────────────────┤
  │ label │ 顯示用中文名稱                    │
  ├───────┼───────────────────────────────────┤
  │ count │ 符合此選項的商品數量              │
  └───────┴───────────────────────────────────┘

  Cache： 1 小時（有資料時才快取）

  ---
  GET /api/products

  取得商品列表，支援篩選與分頁。

  Query Parameters

  ┌───────────────────┬────────┬──────┬────────┬───────────────────────────────────────────────────┐
  │       參數        │  類型  │ 必填 │ 預設值 │                       說明                        │
  ├───────────────────┼────────┼──────┼────────┼───────────────────────────────────────────────────┤
  │ brand             │ string │ 否   │ —      │ 品牌名稱（完全比對）                              │
  ├───────────────────┼────────┼──────┼────────┼───────────────────────────────────────────────────┤
  │ ingredient        │ string │ 否   │ —      │ 包含成分，逗號分隔為 OR 邏輯（如 雞肉,鮭魚）      │
  ├───────────────────┼────────┼──────┼────────┼───────────────────────────────────────────────────┤
  │ excludeIngredient │ string │ 否   │ —      │ 排除成分，逗號分隔為 AND NOT 邏輯（如 牛肉,豬肉） │
  ├───────────────────┼────────┼──────┼────────┼───────────────────────────────────────────────────┤
  │ petType           │ string │ 否   │ —      │ cat 或 dog                                        │
  ├───────────────────┼────────┼──────┼────────┼───────────────────────────────────────────────────┤
  │ form              │ string │ 否   │ —      │ wet（濕食）或 dry（乾糧）                         │
  ├───────────────────┼────────┼──────┼────────┼───────────────────────────────────────────────────┤
  │ isPrescription    │ bool   │ 否   │ —      │ true 篩選處方飼料                                 │
  ├───────────────────┼────────┼──────┼────────┼───────────────────────────────────────────────────┤
  │ page              │ int    │ 否   │ 1      │ 頁碼（最小 1）                                    │
  ├───────────────────┼────────┼──────┼────────┼───────────────────────────────────────────────────┤
  │ limit             │ int    │ 否   │ 24     │ 每頁筆數（1–100）                                 │
  └───────────────────┴────────┴──────┴────────┴───────────────────────────────────────────────────┘

  回應

  {
    "success": true,
    "data": {
      "products": [
        {
          "id": 1,
          "title": "【皇家】貓咪乾糧 2kg",
          "brand": "皇家",
          "petType": "cat",
          "isPrescription": false,
          "form": "dry",
          "ingredientsText": "雞肉、米、玉米...",
          "nutritionText": "蛋白質 32%、脂肪 18%...",
          "proteinPct": 32.0,
          "fatPct": 18.0,
          "fiberPct": 3.5,
          "caloriesText": "4200大卡/kg"
        }
      ],
      "pagination": {
        "page": 1,
        "limit": 24,
        "total": 218,
        "totalPages": 10
      }
    }
  }

  Cache： 5 分鐘（依查詢參數組合各自快取）

  範例

  # 找貓咪濕食，含雞肉但排除牛肉，第 2 頁
  GET /api/products?petType=cat&form=wet&ingredient=雞肉&excludeIngredient=牛肉&page=2
